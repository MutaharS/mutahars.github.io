# Syed Shah portfolio

A static portfolio for Syed Shah, hosted from this GitHub Pages repository. It uses plain HTML and CSS, so there is no build step or package installation.

## Pages

- `index.html` — introduction, selected work, experience, and links
- `work.html` — professional systems case studies
- `search-engine.html` — independent SearchEngine project write-up
- `algorithms.html` — dated LeetCode statistics snapshot and problem-solving focus
- `leetcode-activity.svg` — activity grid reconstructed from the supplied screenshot
- `images/leetcode-2021-activity.png` — profile evidence for 2021 submissions, active days, and longest streak
- `style.css` — shared design system and responsive layouts

## Content maintenance

The algorithm statistics are a snapshot from a profile screenshot dated October 30, 2026. Update the numbers and date in `algorithms.html` and the small homepage preview in `index.html` when you want a new snapshot. The site links to the live LeetCode profile for current figures.

Professional case studies describe architecture and outcomes at a high level. Review public wording before publishing new employer details or metrics.

The older project videos and Bootstrap files are retained in the repository but are not loaded by the redesigned pages.
